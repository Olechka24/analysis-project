# Анализ датасета «Price of Flats in Moscow»
Учебный проект по дисциплине «Введение в проектную деятельность».  
Цель работы — провести анализ данных о стоимости квартир в Москве, выполнить очистку, визуализацию и сформировать выводы на основе исследовательского анализа данных (EDA).

## Цели проекта
- изучить структуру датасета;
- выполнить первичную обработку данных;
- провести разведочный анализ (EDA);
- выявить зависимости между признаками;
- подготовить данные для дальнейшего анализа или моделирования.
  
## Структура репозитория
- **analysis.ipynb** — основной Jupyter Notebook с анализом данных;  
- **flats_moscow.csv** — датасет с информацией о квартирах;  
- **README.md** — описание проекта.

## Описание данных
Датасет содержит информацию о квартирах в Москве.  
Основные признаки:

- площадь квартиры;  
- количество комнат;  
- этаж и этажность дома;  
- расстояние до метро;  
- цена квартиры;  
- дополнительные параметры (если есть в датасете).

## Этапы анализа
1. **Загрузка и первичный осмотр данных**  
   - просмотр структуры (`info`, `describe`);  
   - проверка пропусков и дубликатов.

2. **Очистка данных**  
   - удаление выбросов;  
   - обработка пропусков;  
   - приведение типов.

3. **Разведочный анализ (EDA)**  
   - гистограммы распределений;  
   - диаграммы рассеяния;  
   - boxplot для анализа выбросов;  
   - корреляционная матрица.

4. **Создание новых признаков**  
   - цена за квадратный метр;  
   - бинарные признаки (например, близость к метро).

5. **Финальные визуализации и выводы**
   - анализ ключевых зависимостей;  
   - формирование итоговых наблюдений.
